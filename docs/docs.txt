uses PostgreSQL for persistence, 
Terraform for infrastructure provisioning, 
and GitHub Actions for continuous integration and deployment."

Useful Docker Compose Commands:
cd to deployment directory

start postgres:
docker compose up -d postgres

apply prisma migration:
docker compose run --rm backend npx prisma migrate deploy

Local development
docker compose up --build or docker compose up -d

check prisma migration
docker exec -it formflow-backend npx prisma migrate status

Uses:

docker-compose.yml
Azure production
docker compose \
  --env-file .env \
  -f docker-compose.prod.yml \
  up -d

Uses:

docker-compose.prod.yml

start all existing containers:
docker compose up -d

Open:
http://localhost

Stop all services:
docker compose down

View logs from all services:
docker compose logs -f

View logs for the frontend:
docker logs formflow-frontend --tail=100

View logs for the backend:
docker logs formflow-backend --tail=100

check frontend container:
docker exec formflow-frontend printenv | grep PORT

Stop and remove volumes (this deletes your PostgreSQL data)
docker compose down -v
Rebuild after code changes

If you change the Dockerfile, package dependencies, or build output:
docker compose up --build -d

confirm docker network
docker network ls
