Useful Docker Compose Commands:
cd to deployment directory

start postgres:
docker compose up -d postgres

apply prisma migration:
docker compose run --rm backend npx prisma migrate deploy

Local development
docker compose up --build or docker compose up -d

verify the validity of docker compose file:
docker compose --env-file .env.production -f docker-compose.prod.yml config

check prisma migration
docker exec -it formflow-backend npx prisma migrate status

The workflow:
docker compose -f docker-compose.prod.yml --env-file .env.production build

followed by:
docker compose -f docker-compose.prod.yml --env-file .env.production push

Uses:
docker-compose.prod.yml

start all existing containers:
docker compose up -d

Open:
http://localhost

Stop all services:
docker compose down

View logs from all services:
docker compose logs -f

View logs for the frontend:
docker logs formflow-frontend --tail=100

View logs for the backend:
docker logs formflow-backend --tail=100

check frontend container:
docker exec formflow-frontend printenv | grep PORT

Stop and remove volumes (this deletes your PostgreSQL data)
docker compose down -v
Rebuild after code changes

If you change the Dockerfile, package dependencies, or build output:
docker compose up --build -d

confirm docker network
docker network ls

debug prisma table
docker exec -it formflow-postgres psql -U postgres -d formflow

then:
\dt

docker exec -it formflow-backend npx prisma migrate status

check prisma schema inside container:
docker exec formflow-backend cat prisma/schema.prisma

deploy migration:
docker exec -it formflow-backend npx prisma migrate deploy

verify tables:
docker exec -it formflow-postgres psql -U postgres -d formflow
